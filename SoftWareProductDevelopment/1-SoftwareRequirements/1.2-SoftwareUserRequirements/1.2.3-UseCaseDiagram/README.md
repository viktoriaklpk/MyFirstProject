### Діаграма прецедентів програмного продукту

Актори:
- Користувач
- Адміністратор
- Сервіс доставки їжі
- Сервіс сповіщень

Прецеденти:
- Авторизувати користувача
- Переглянути заклади харчування
- Замовити їжу
- Отримати повідомлення про безпеку
- Надіслати професійне повідомлення
- Переглянути матеріали з живопису
- Зберегти улюблені роботи

Include-зв’язки:
- «Замовити їжу» include «Авторизувати користувача»
- «Надіслати професійне повідомлення» include «Авторизувати користувача»
- «Зберегти улюблені роботи» include «Авторизувати користувача»

Extend-зв’язки:
- «Отримати повідомлення про безпеку» extend «Сервіс сповіщень»
