### Аналіз інформаційних потреб

| Потреба | доступність | зрозумілість | цінність | актуальність |
|---|---|---|---|---|
| їжа | дорого | - | - | - |
| особиста безпека | - | незрозуміло | - | запізно |
| професійне спілкування | - | - | дорого | - |
| зацікавленість живописом | неможливо | - | - | - |

Пошук якісної та корисної інформації про здорове харчування часто є дорогим через платні сервіси та консультації.

Інформація щодо особистої безпеки може бути незрозумілою або надходити із запізненням.

Професійні платформи для спілкування часто мають платний функціонал.

Користувачу складно швидко знаходити якісні матеріали та рекомендації щодо живопису.
