### Прототипи методів програмних класів

| FR | Опис вимоги | Назва класу | Назва методу класу |
|---|---|---|---|
| FR1.1 | Авторизація користувача | User | login() |
| FR1.2 | Вихід користувача | User | logout() |
| FR2.1 | Створення замовлення | Order | createOrder() |
| FR2.2 | Скасування замовлення | Order | cancelOrder() |
| FR3.1 | Перегляд меню | FoodPlace | getMenu() |
| FR4.1 | Перегляд роботи | Artwork | showArtwork() |
| FR5.1 | Надсилання сповіщення | Notification | sendNotification() |
