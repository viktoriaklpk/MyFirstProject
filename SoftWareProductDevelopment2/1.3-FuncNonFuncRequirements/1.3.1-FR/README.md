### Опис функціональних вимог

| FR | Опис функціональної вимоги |
|---|---|
| FR1 | Авторизувати користувача |
| FR1.1 | Користувач передає параметри ідентифікації та аутентифікації |
| FR1.2 | ПП надає доступ до функцій користувача |
| FR2 | Замовити їжу |
| FR2.1 | ПП надає перелік закладів харчування |
| FR2.2 | Користувач обирає заклад харчування |
| FR2.3 | Користувач формує замовлення |
| FR2.4 | ПП передає замовлення сервісу доставки |
| FR3 | Отримати повідомлення про безпеку |
| FR3.1 | ПП отримує інформацію про небезпечні ситуації |
| FR3.2 | ПП надсилає повідомлення користувачу |
| FR4 | Професійне спілкування |
| FR4.1 | Користувач надсилає професійне повідомлення |
| FR4.2 | ПП передає повідомлення іншому користувачу |
| FR5 | Перегляд матеріалів з живопису |
| FR5.1 | ПП надає перелік навчальних матеріалів |
| FR5.2 | Користувач переглядає матеріали |
| FR5.3 | Користувач зберігає улюблені роботи |
